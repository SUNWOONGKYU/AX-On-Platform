## Task 목표
개별 AI 전문가의 상세 프로필을 표시하는 템플릿 페이지를 구현한다.
expert.html의 전문가 카드에서 링크로 연결되는 상세 페이지이다.

### 구현 내용
- **프로필 헤더**: 전문가 사진, 이름, 직함, 주요 전문 분야
- **소개 섹션**: 경력 및 전문성 소개
- **전문 분야 태그**: 기술 스택 및 전문 분야 태그
- **경력 사항**: 주요 경력 및 프로젝트
- **연락/상담 CTA**: 상담 신청 또는 문의 버튼
- **URL 파라미터**: `?id={expert_id}` 로 동적 로딩
