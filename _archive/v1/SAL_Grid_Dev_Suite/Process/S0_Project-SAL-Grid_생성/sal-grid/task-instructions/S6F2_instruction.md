## 배경 및 목적

`community.html`의 오른쪽 사이드바에 "AI 지식 허브" 섹션이 있으나 콘텐츠가 빈약하다. AX-On Platform의 핵심 가치인 AI 활용 교육과 커뮤니티 지원을 강화하기 위해, AI 활용 가이드, SAL Grid 소개, AI 창업 사례 등 유용한 콘텐츠 링크를 추가하여 사이드바를 풍부하게 만든다.

## 세부 작업 지시

1. `community.html`의 오른쪽 사이드바에서 "AI 지식 허브" 섹션을 찾는다.

2. 다음 메뉴 항목들을 추가한다:

   **AI 활용 가이드 (3개 이상)**
   - "ChatGPT 업무 활용 10가지 방법" → 내부 또는 외부 링크
   - "AI 프롬프트 작성 기초 가이드" → 내부 콘텐츠
   - "Claude로 코드 작성하기" → 내부 콘텐츠

   **SAL Grid 소개**
   - "SAL Grid 개발 방법론이란?" → 플랫폼 소개 페이지
   - "3D 좌표계로 프로젝트 관리하기" → 가이드 페이지

   **AI 창업 성공 사례 (2개 이상)**
   - 시니어 AI 창업 성공 스토리
   - AI 전문가 인터뷰

3. 각 메뉴 항목을 시각적으로 구분하기 위한 카테고리 헤딩을 추가한다.

4. 메뉴 항목 디자인을 통일한다:
   - 아이콘 + 제목 + 간단한 설명 형식
   - hover 시 시각적 피드백
   - 새 탭 또는 모달로 콘텐츠 표시

5. 기존 플랫폼 디자인 시스템(`--ink`, `--surface`, accent 색상)을 따른다.

6. "더 많은 리소스 보기" 버튼 또는 링크를 추가하여 확장성을 고려한다.
