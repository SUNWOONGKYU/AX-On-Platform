## Task 목표
AX-On Platform의 메인 랜딩 페이지를 구현한다.
4대 메뉴(우리의 창업, AX 프로젝트, AI 전문가, 커뮤니티) 히어로 섹션과
전체 네비게이션을 구성한다.

### 구현 내용
- **네비게이션 바**: 로고, 4대 메뉴 링크, 로그인/회원가입 버튼
- **히어로 섹션**: 플랫폼 소개 및 4대 메뉴 카드
- **각 메뉴 카드**: 메뉴별 액센트 색상 적용, 설명, 링크 연결
- **푸터**: 이용약관, 개인정보처리방침, 문의하기 링크
