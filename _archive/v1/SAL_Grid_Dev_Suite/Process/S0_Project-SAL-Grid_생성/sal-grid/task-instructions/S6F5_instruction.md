## 배경 및 목적

커뮤니티 페이지에서 사용자가 게시글이나 댓글에 투표(UP/DOWN)할 때마다 전체 피드가 다시 렌더링되고 있다. 이는 성능 저하와 UX 문제(스크롤 위치 변경 등)를 야기한다. 투표가 발생했을 때 해당 게시글 카드만 업데이트하도록 부분 렌더링으로 최적화한다.

## 생성/수정 대상 파일

| 파일 경로 | 변경 내용 |
|----------|----------|
| `pages/community.js` | 투표 렌더링 로직 최적화 |

## 세부 작업 지시

1. 현재 투표 기능 분석:
   - 투표 클릭 시 `renderFeed()` 함수가 전체 피드를 재렌더링하는지 확인
   - 불필요한 DOM 조작 식별

2. 부분 렌더링 함수 작성:
   - `updatePostVote(postId, voteCount)` 함수 추가
   - 특정 게시글 카드의 투표 수만 업데이트
   - 투표 상태(UP/DOWN) 아이콘 업데이트

3. 투표 이벤트 리스너 수정:
   - 투표 버튼 클릭 시 `updatePostVote()` 호출
   - API 응답 후 UI 업데이트

4. 성능 최적화:
   - 불필요한 이미지 리로드 방지
   - DOM 쿼리 최소화
   - 메모리 누수 방지

5. 테스트:
   - 투표 후 전체 피드가 새로고침되지 않는지 확인
   - 스크롤 위치가 유지되는지 확인
   - 투표 수가 정확히 표시되는지 확인
