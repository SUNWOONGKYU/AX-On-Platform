## 배경 및 목적

네비게이션 바에서 사용자 인증 상태를 확인하고 메뉴를 변경하는 로직이 여러 파일에 중복되어 있다. 이를 공유 모듈로 추출하여 코드 중복을 제거하고 유지보수성을 향상시킨다.

## 생성/수정 대상 파일

| 파일 경로 | 변경 내용 |
|----------|----------|
| `pages/components/nav-auth.js` | 네비게이션 인증 모듈 추출 |
| `pages/*.html` | 중복된 인증 코드 제거, 모듈 호출로 변경 |

## 세부 작업 지시

1. 현재 인증 코드 분석:
   - 7개 파일에 중복된 인증 로직 확인
   - 공통 부분 식별 (사용자 확인, 로그인/로그아웃 버튼 토글 등)

2. `nav-auth.js` 모듈 작성:
   ```javascript
   async function updateNavbar() {
     const user = await getCurrentUser();
     if (user) {
       // 로그인 상태: 로그아웃 버튼, 프로필 링크 표시
     } else {
       // 미로그인 상태: 로그인 버튼 표시
     }
   }
   ```

3. 각 HTML 파일에서 모듈 호출:
   - `<script src="components/nav-auth.js"></script>`
   - `updateNavbar();` 호출

4. 중복된 코드 제거:
   - 각 파일에서 인증 관련 코드 삭제
   - 모듈에서 처리하도록 변경

5. 테스트:
   - 로그인 전: 미로그인 상태 네비게이션 표시
   - 로그인 후: 로그인 상태 네비게이션 표시
   - 로그아웃 후: 미로그인 상태로 복귀
