## 배경 및 목적

사용자가 프로그램에 수강신청할 때 실제 결제가 이루어져야 한다. 결제 게이트웨이 제공자(토스페이먼츠, 카카오페이 등)와 연동하여 사용자가 신용카드, 계좌이체, 모바일 결제 등으로 결제할 수 있도록 구현한다. 결제 성공 시 자동으로 `enrollments` 테이블에 등록된다.

## 생성/수정 대상 파일

| 파일 경로 | 변경 내용 |
|----------|----------|
| `pages/enrollment.js` | 결제 게이트웨이 연동 |
| `api/payment-webhook.js` | 결제 완료 웹훅 처리 |

## 세부 작업 지시

1. **PO 협력 필요**: 다음 정보를 제공해야 함:
   - 사용할 결제 게이트웨이 (토스페이먼츠/카카오페이/아임포트 등)
   - 가맹점 ID 및 API 키
   - 결제 수수료율
   - 환불 정책

2. 결제 게이트웨이 SDK 통합:
   - 선택된 PG사의 JavaScript SDK 추가
   - 결제 요청 함수 구현

3. 결제 요청 구현 (`enrollment.js`):
   - "수강신청" 버튼 클릭
   - 결제 팝업/모달 표시
   - 사용자가 결제 수단 선택 및 결제 진행
   - 결제 성공/실패 처리

4. 웹훅 처리 (`payment-webhook.js`):
   - PG사로부터 결제 완료 알림 수신
   - 결제 정보 검증
   - `enrollments` 테이블에 신규 등록

5. 에러 처리:
   - 결제 실패 시 사용자 안내
   - 결제 취소 처리
   - 환불 프로세스
