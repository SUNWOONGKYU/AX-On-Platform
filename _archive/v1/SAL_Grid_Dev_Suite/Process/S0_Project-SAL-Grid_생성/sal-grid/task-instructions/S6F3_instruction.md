## 배경 및 목적

AX 플랫폼의 프로젝트 관리자가 접수된 프로젝트들의 현황을 한눈에 볼 수 있는 대시보드가 필요하다. 접수된 프로젝트의 현황, 진행 상태, 담당자 정보 등을 관리하는 어드민 페이지를 구현한다. 이를 통해 프로젝트 진행 상황을 효율적으로 추적하고 관리할 수 있다.

## 생성/수정 대상 파일

| 파일 경로 | 변경 내용 |
|----------|----------|
| `pages/admin-dashboard.html` | 관리자 대시보드 HTML 구현 |
| `pages/admin-dashboard.js` | 대시보드 로직 및 데이터 조회 |

## 세부 작업 지시

1. `admin-dashboard.html` 파일 생성:
   - 프로젝트 목록 테이블 (프로젝트명, 접수일, 진행 상태, 담당자)
   - 상태별 필터 (대기중, 진행중, 완료)
   - 검색 기능
   - 프로젝트 상세 보기 링크

2. `admin-dashboard.js` 작성:
   - 관리자 권한 확인 (인증되지 않으면 리다이렉트)
   - 접수된 프로젝트 목록 조회
   - 필터 및 검색 기능 구현
   - 프로젝트 상태 업데이트 기능

3. 대시보드 통계:
   - 총 프로젝트 수
   - 진행중인 프로젝트
   - 완료된 프로젝트
   - 평균 처리 기간

4. CSS 스타일링:
   - 반응형 테이블 디자인
   - 상태 시각화 (색상 코드)
   - 아이콘 추가
