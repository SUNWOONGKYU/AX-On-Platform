## 배경 및 목적

로그인 후 네비게이션의 "마이페이지" 링크가 `pages/auth/profile.html`을 가리키지만 파일이 존재하지 않아 404 오류가 발생한다. 사용자가 본인의 프로필 정보를 확인하고 수정하며, 수강신청 내역, AX 프로젝트 접수 내역, 커뮤니티 활동 내역을 한 곳에서 확인할 수 있는 마이페이지를 구현한다.

## 세부 작업 지시

1. `pages/auth/profile.html` 파일을 신규 생성한다.

2. 페이지 레이아웃을 설계한다:
   - 상단: 공통 네비게이션 (다른 페이지와 동일)
   - 왼쪽 사이드바: 메뉴 (프로필, 수강 내역, AX 프로젝트, 커뮤니티 활동)
   - 메인 영역: 선택된 섹션 콘텐츠
   - 하단: 공통 푸터

3. 프로필 섹션을 구현한다:
   - `profiles` 테이블에서 현재 사용자 데이터 로드
   - 표시 항목: 이름, 이메일(읽기 전용), 역할, 소개글, 전화번호, 관심 분야
   - 수정 폼과 저장 버튼 구현
   - 아바타 이미지 업로드 기능 (Supabase Storage 연동)

4. 수강신청 내역 섹션을 구현한다:
   - `enrollments` 테이블에서 본인 레코드 조회
   - 프로그램명, 신청일, 결제 상태 표시

5. AX 프로젝트 접수 내역 섹션을 구현한다:
   - `ax_project_requests` 테이블에서 본인 레코드 조회
   - 프로젝트명, 접수일, 처리 상태 표시

6. 커뮤니티 활동 내역 섹션을 구현한다:
   - `posts` 테이블에서 본인 게시글 목록 조회
   - 게시글 제목, 작성일, 조회수, 좋아요 수 표시

7. 디자인 시스템을 적용한다:
   - CSS 변수: `--ink`, `--surface`, accent 색상 등 기존 페이지와 통일
   - 반응형 레이아웃 (모바일 breakpoint 768px)
   - 공통 네비게이션/푸터 스타일 적용

8. 비로그인 사용자 접근 시 로그인 페이지로 리디렉션한다.
