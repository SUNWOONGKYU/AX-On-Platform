AX-On 방법론

AX-On이 기업 AX 프로젝트를 추진하는 방식 — 이론 체계(How we think) + 실행 자산(What we apply).

PART 1 / HOW WE THINK

이론 체계 — 4개 자체 IP

DID System · SAL Grid_AX(특허 출원) · Platoon Formation(특허 출원) · SAL Task Analysis. 네 자산이 함께 작동해 12 Areas × DID 양 축의 혁신을 가능하게 합니다.

① DID SYSTEM
DID System — Data → Information → Decision

조직의 모든 업무 데이터를 L1 데이터 → L2 정보 → L3 의사결정의 흐름으로 연결하는 3 Layer 시스템. L3의 결과가 다시 L1으로 유입되는 자가 개선 순환 구조를 가집니다. 12 Areas 업무 혁신과 유기적으로 순환하면서 ROI 증대의 근원이 됩니다.

DID 상세 구조 보기 →

② SAL GRID_AX 특허 출원
SAL Grid_AX — Stage × Area × Level 3차원 좌표계

AX 프로젝트의 모든 Task를 3개 축에 위치시켜 체계적으로 관리합니다. 어디까지 왔고(Stage), 어느 영역에서(Area), 얼마나 깊이(Level) 진행되었는지를 좌표 하나로 표현합니다.

좌표를 보면 어느 단계의 어느 영역의 어떤 깊이에 있는 Task인지 한눈에 파악됩니다. 90개 Task × 25개 속성 규모의 프로젝트도 좌표 한 줄로 추적 가능합니다.
특허 출원: SAL Grid_AX의 좌표 체계와 운영 방법은 특허 출원 중입니다. 세부 청구항은 출원·등록 이후 안내합니다.
③ PLATOON FORMATION 특허 출원
Platoon Formation — AI 에이전트의 소대 편제

군 소대 편제(소대장/분대장/분대원 3계층)를 AI 에이전트 팀에 응용합니다. 여러 분대가 병렬로 투입되어 구축 속도를 극대화합니다. 한 분대가 막히면 다른 분대가 계속 전진하므로 전체 일정이 안정적입니다.

④ SAL TASK ANALYSIS
STA — 5 Parts · 25 속성 · H·A·R·P·X

SAL Grid 좌표 위의 각 Task를 5개 Part(H·A·R·P·X), 총 25개 속성으로 분석합니다. "SAL Grid_AX가 지도라면, STA는 그 지도 위의 각 지점을 탐사하는 도구"입니다.

Part의미속성 수
HHeader (식별·메타)5개
AActivity (활동·산출물)5개
RResource (리소스)5개
PProcess (실행 프로세스)6개
XeXecution (실행·검증)4개
Phase 1에서 H·A·R이 채워지고, Phase 2 이후 P·X가 활성화되어 실행·검증까지 추적합니다.
