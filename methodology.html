AX-On 방법론

AX-On이 기업 AX 프로젝트를 추진하는 방식 — DID System · SAL Grid_AX · Platoon Formation · SAL Task Analysis, 4개 자체 IP로 구성됩니다.

FOUR PROPRIETARY IP

AX-On 4개 자체 IP

DID System · SAL Grid_AX · Platoon Formation · SAL Task Analysis. 네 자산이 함께 작동해 Areas × DID 양 축의 혁신을 가능하게 합니다.

① DID SYSTEM
DID System — Data → Information → Decision

조직의 모든 업무 데이터를 L1 데이터 → L2 정보 → L3 의사결정의 흐름으로 연결하는 3 Layer 시스템. L3의 결과가 다시 L1으로 유입되는 자가 개선 순환 구조를 가집니다. Areas 업무 혁신과 유기적으로 순환하면서 ROI 증대의 근원이 됩니다.

DID 상세 구조 보기 →

② SAL GRID_AX
SAL Grid_AX — Stage × Area × Level 3차원 좌표계

AX 프로젝트의 모든 Task를 3개 축에 위치시켜 체계적으로 관리합니다. 각 업무(Task)가 업무 흐름의 어디에 있는지(Stage), 어느 영역인지(Area), 어느 깊이인지(Level)를 좌표 하나로 표현합니다.

3개 축

S
Stage
업무 흐름 단계 — 선후 의존성을 가진 시간축 (S1 → S2 → … → Sn)
A
Area
Areas 중 어느 영역
L
Level
각 셀 내 실행 항목 순서

Stage 정의 (S축) — 산업·기업별로 다름

Stage는 각 산업·기업의 본업 업무 흐름을 따라 정의됩니다. 앞 Stage가 끝나야 다음 Stage가 시작되는 선후 의존성을 갖고, 각 Stage 경계에서 Stage Gate로 품질을 검증합니다.

산업업무 흐름 (S1 → … → Sn)
엔지니어링영업/수주 → 착수/계획 → 조사·분석 → 설계·용역수행 → 검토·납품 → 사후관리
건설사업기획 → 설계 → 분양 → 시공 → 준공/사후
아카이브구축상담 → 아카이브설계 → 자료수집 → 디지털화·메타 → 시스템등록 → 운영·서비스 → 사후관리

좌표를 보면 업무 흐름의 어느 단계, 어느 영역, 어떤 깊이에 있는 Task인지 한눈에 파악됩니다. 90개 Task × 약 25개 속성 규모의 프로젝트도 좌표 한 줄로 추적 가능합니다.

③ PLATOON FORMATION
Platoon Formation — AI 에이전트의 소대 편제

군 소대 편제(소대장/분대장/분대원 3계층)를 AI 에이전트 팀에 응용합니다. 여러 분대가 병렬로 투입되어 구축 속도를 극대화합니다. 한 분대가 막히면 다른 분대가 계속 전진하므로 전체 일정이 안정적입니다.

④ SAL TASK ANALYSIS
STA — 5 Parts · 약 25 속성 · H·A·R·P·X

SAL Grid 좌표 위의 각 Task를 5개 Part(H·A·R·P·X), 약 25개 속성으로 분석합니다. "SAL Grid_AX가 지도라면, STA는 그 지도 위의 각 지점을 탐사하는 도구"입니다.

Part의미속성 수
HHuman — 사람이 수행하는 영역 (담당·역할·책임)7개
AAI — AI가 수행·협업하는 영역 (모델·도구·자동화)11개
RRanking — 우선순위·중요도 평가2개
PPlanning — 일정·자원 계획2개
XeXecution — 실행·검증4개
Step 1에서 H·A·R이 채워지고, Step 2 이후 P·X가 활성화되어 실행·검증까지 추적합니다.
