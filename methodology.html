METHODOLOGY

AX-On 방법론

SAL Grid로 모든 업무를 3차원 좌표로 분해하고, STA로 각 업무의 25개 속성을 분석합니다.
실행 단계에서 Platoon Formation으로 AI 에이전트 소대 편제를 투입합니다.
3개 자체 IP가 분해 → 분석 → 실행의 한 체계로 결합되어 AX 프로젝트를 추진합니다.

① SAL GRID

SAL Grid — Stage × Area × Level 3차원 좌표계

SAL Grid는 AX 프로젝트의 모든 Task를 Stage·Area·Level 3개 축으로 분해하여 정리합니다. 각 Task는 자신만의 좌표(예: S1TR1)를 갖습니다.

3개 축

S
Stage
업무 흐름 단계 — 선후 의존성을 가진 시간축 (S1 → S2 → … → Sn)
A
Area
Areas 중 어느 영역
L
Level
각 Area 내 실행 순서

Stage 정의 (S축) — 산업·조직별로 다름

Stage는 각 산업·조직의 본업 업무 흐름을 따라 정의됩니다. 앞 Stage가 끝나야 다음 Stage가 시작되는 선후 의존성을 갖습니다.

산업업무 흐름 (S1 → … → Sn)
엔지니어링영업/수주 → 착수/계획 → 조사·분석 → 설계·용역수행 → 검토·납품 → 사후관리
건설사업기획 → 설계 → 분양 → 시공 → 준공/사후
아카이브구축상담 → 아카이브설계 → 자료수집 → 디지털화·메타 → 시스템등록 → 운영·서비스 → 사후관리

② PLATOON FORMATION

Platoon Formation — AI 에이전트의 소대 편제

군 소대 편제 원리를 AI 에이전트 팀 편성에 응용합니다. 소대장 · 분대장 · 분대원 · 용병(외부 AI)의 4계층으로 구성됩니다.

군사용어 ↔ 기술용어 대응

군사 편제 용어는 계층적 역할과 지휘 관계를 직관적으로 표현하기 위한 기술적 비유(Technical Analogy)입니다.

③ SAL TASK ANALYSIS

STA — 5 Parts · 25 속성 · H·A·R·P·X

SAL Grid 좌표 위의 각 Task를 5개 Part(H·A·R·P·X), 25개 속성으로 분석합니다. "SAL Grid가 지도라면, STA는 그 지도 위의 각 지점을 탐사하는 도구"입니다.

단계코드이름누가속성 수내용
Step 1
진단		HHuman (담당자 작성)사람7개현업 담당자가 직접 답변하는 업무 현황 (H1~H7)
AAI (자동수집)AI11개AI가 자동 파악하는 데이터 (A1~A11)
RRank (순위)시스템1개종합 점수 + 우선순위 자동 산출
Step 2
추진		PPlanning (계획)PM2개담당팀, 목표일 (P1~P2)
XeXecution (실행)시스템4개상태, 진행률, 이슈, 검증 (X1~X4)
범례 H Human (담당자 작성) A AI (자동수집) R Rank (순위) P Planning (계획) X eXecution (실행)

R 산출 공식 — 우선순위 자동화의 핵심

H(현업 인터뷰)와 A(AI 자동수집)에서 모은 데이터를 4개 변수로 결합하여 자동화 우선순위를 정량화합니다.

R = (H4 + H5반전 + A6 + A7) × A10 ÷ A8
H4 반복성 (높을수록 자동화 효과 ↑) H5반전 예외·판단 (낮을수록 자동화 쉬움) A6 디지털화 수준 A7 업무 구조화 수준 × A10 예상 시간 절감량 (효과 가중) ÷ A8 오류 영향 심각도 (위험 페널티)
H5반전: 예외·판단이 높을수록 자동화 어려움 → 높음=1, 낮음=5로 반전 처리

Step 1·2 흐름 — 진단에서 실행까지

STA는 Step 1 진단(H · A · R)과 Step 2 추진(P · X)으로 분리됩니다. Step 1에서 우선순위가 매겨진 Task만 Step 2 추진 단계로 진입합니다.

  1. H현업 담당자 인터뷰 → 7개 항목 수집
  2. A시스템 로그·조직도 분석 → AI가 11개 항목 자동 수집
  3. R공식 적용 → 점수순 자동 정렬 (Step 1 종료)
  4. P상위 Task에 분대(Alpha/Bravo/Charlie/Delta) + 목표일 배정
  5. X실행 · 진행률 추적 · 이슈 기록 · 검증 (Step 2 종료)

적용 규모

SCALE 1
90 Task × 25 속성 = 2,250 데이터 포인트
엔지니어링 용역(KD 적용 사례) 기준. 한 프로젝트 진단에 2,250개의 분석 Grid가 자동 채워짐.
SCALE 2
H 7 + A 11 = 18개 진단 입력
Step 1만으로도 18차원 진단. 사람과 AI가 역할 분담하여 인터뷰 부담 최소화.
SCALE 3
단일 R 점수 → 우선순위 자동 정렬
의사결정자가 우선순위 회의로 며칠 소비할 필요 없이, 공식이 객관적 정렬을 즉시 산출.
흐름: H(인터뷰) → A(AI 자동수집) → R(순위 산출) — 여기까지가 진단. → P(계획) → X(실행·검증) → 다음 Task.
