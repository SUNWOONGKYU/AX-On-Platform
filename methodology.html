AX-On 방법론

AX-On이 AX 프로젝트를 추진하는 방식 — SAL Grid · Platoon Formation · SAL Task Analysis, 3개 자체 IP로 구성됩니다.

① SAL GRID

SAL Grid — Stage × Area × Level 3차원 좌표계

SAL Grid는 AX 프로젝트의 모든 Task를 Stage·Area·Level 3개 축으로 분해하여 정리합니다. 각 Task는 자신만의 좌표(예: S1TR1)를 갖습니다.

3개 축

S
Stage
업무 흐름 단계 — 선후 의존성을 가진 시간축 (S1 → S2 → … → Sn)
A
Area
Areas 중 어느 영역
L
Level
각 셀 내 실행 항목 순서

Stage 정의 (S축) — 산업·조직별로 다름

Stage는 각 산업·조직의 본업 업무 흐름을 따라 정의됩니다. 앞 Stage가 끝나야 다음 Stage가 시작되는 선후 의존성을 갖습니다.

산업업무 흐름 (S1 → … → Sn)
엔지니어링영업/수주 → 착수/계획 → 조사·분석 → 설계·용역수행 → 검토·납품 → 사후관리
건설사업기획 → 설계 → 분양 → 시공 → 준공/사후
아카이브구축상담 → 아카이브설계 → 자료수집 → 디지털화·메타 → 시스템등록 → 운영·서비스 → 사후관리

② PLATOON FORMATION

Platoon Formation — AI 에이전트의 소대 편제

군 소대 편제(소대장/분대장/분대원 3계층)를 AI 에이전트 팀에 응용합니다. 여러 분대가 병렬로 투입되어 구축 속도를 극대화합니다. 한 분대가 막히면 다른 분대가 계속 전진하므로 전체 일정이 안정적입니다.

3계층 구조

분대장 B영역 책임
분대장 C영역 책임
↓
분대원실행 Task
분대원실행 Task
분대원실행 Task

③ SAL TASK ANALYSIS

STA — 5 Parts · 25 속성 · H·A·R·P·X

SAL Grid 좌표 위의 각 Task를 5개 Part(H·A·R·P·X), 25개 속성으로 분석합니다. "SAL Grid가 지도라면, STA는 그 지도 위의 각 지점을 탐사하는 도구"입니다.

단계코드이름누가속성 수내용
Step 1
진단		HHuman (담당자 작성)사람7개현업 담당자가 직접 답변하는 업무 현황 (H1~H7)
AAI (자동수집)AI11개AI가 자동 파악하는 데이터 (A1~A11)
RRank (순위)시스템1개종합 점수 + 우선순위 자동 산출
Step 2
추진		PPlanning (계획)PM2개담당팀, 목표일 (P1~P2)
XeXecution (실행)시스템4개상태, 진행률, 이슈, 검증 (X1~X4)
흐름: H(인터뷰) → A(AI 자동수집) → R(순위 산출) — 여기까지가 진단. → P(계획) → X(실행·검증) → 다음 Task.
