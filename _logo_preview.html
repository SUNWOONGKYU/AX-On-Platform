AX-On 로고 신규 4종 (V2 — 창의)

보편 모티프(모노그램·화살표) 탈피. 컨셉 차별화 우선.

옵션 1 · 진원지
Pulse Origin

한 점에서 파장이 퍼지는 진원지 메타포. "AX-On은 변혁의 시작점이자 발신지"

AX-On
AX-On
컨셉: 진원지·발신지·파장. AX-On이 변혁의 진원
장점: 모던 미니멀, 애니메이션 가능, 모든 크기 잘 작동
차별: 텍스트 의존 없음. 순수 기하학.
옵션 2 · 전원 ON
Power Switch X

표준 전원 버튼(⏻) 픽토그램의 갭에 X 삽입. "AX를 켜는 스위치"

AX-On
AX-On
컨셉: 전원 ON 픽토그램 + X. "AX를 켜다" 직역
장점: 보편 인지(전원 버튼은 누구나 앎), 강력한 메시지
차별: 표준 전원 아이콘의 직선을 X로 치환 (유일성)
옵션 3 · 입체
Origami X

종이접기 X — 평면이 접혀 입체로. "평면적 사고 → 입체적 변혁"

AX-On
AX-On
컨셉: 종이접기 / 폴리곤 X. "2D → 3D, 평면 → 입체 = 변혁"
장점: 입체감으로 강한 시각 임팩트, 4면 음영으로 깊이감
차별: 단색이 아닌 다이아몬드 facet 표현 (가장 독특)
옵션 4 · 네트워크
Constellation X

별자리/네트워크 X — 점과 선의 연결. "전문가들이 만나 X 형상"

AX-On
AX-On
컨셉: 4 노드 + X 연결 + 중앙 허브. "전문가 풀의 네트워크 = AX-On"
장점: 네트워크 의미가 사업 본질(전문가 매칭) 정확히 반영
차별: 점·선·허브 3 요소 — 별자리 같은 정체성
Bonus · 워드마크 형태

로고 마크 없이 워드마크만 가는 방향

Stripe·Vercel·Linear처럼 마크 없이 텍스트만으로 강한 정체성

AX·On
AX·On
AX/On

구분자 변경 (- → · → /) + 폰트 무게 강화 = 마크 없어도 충분히 강함

선택 가이드
1 (Pulse Origin): 기술·미래 지향 · 모던 미니멀 추구
2 (Power X): 메시지 명확 · 보편 인지율 최우선
3 (Origami X): 디자인 임팩트 · 입체감 차별화
4 (Constellation X): 네트워크/플랫폼 사업 본질 강조
Bonus (워드마크): 마크 없는 미니멀 — Stripe 스타일
