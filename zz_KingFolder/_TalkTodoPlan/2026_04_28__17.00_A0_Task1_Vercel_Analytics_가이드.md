## Step 2. 트래킹 스크립트 삽입 (10분)

AX-On은 정적 HTML 9개 파일이므로 npm 패키지가 아닌 **CDN 스크립트** 방식 채택.

### 9개 페이지 모두 `</body>` 직전에 추가

```html
<!-- Vercel Analytics (A0 Task 1, 2026-04-28~) -->
<script defer src="/_vercel/insights/script.js"></script>
<script defer src="/_vercel/speed-insights/script.js"></script>

<!-- 그룹 퍼널 이벤트 트래킹 -->
<script>
  // 페이지 그룹 자동 분류 (4그룹)
  (function() {
    var path = window.location.pathname;
    var group = 'unknown';
    if (/index|ax-project/.test(path)) group = 'conversion';
    else if (/about-ax|methodology/.test(path)) group = 'content';
    else if (/community|pool/.test(path)) group = 'community';
    else if (/terms|privacy/.test(path)) group = 'legal';

    // 페이지뷰 + 그룹 태그
    if (window.va) {
      window.va('event', { name: 'pageview_group', group: group, path: path });
    }

    // Hero CTA 클릭 (Conversion 그룹만)
    if (group === 'conversion') {
      document.addEventListener('click', function(e) {
        var t = e.target.closest('[data-cta]');
        if (t && window.va) {
          window.va('event', { name: 'hero_cta_click', cta: t.dataset.cta, path: path });
        }
      });
    }
  })();
</script>
</body>
```

### 적용 대상 9개 파일

| # | 파일 | 그룹 |
|---|---|:---:|
| 1 | `index.html` | conversion |
| 2 | `pages/ax-project.html` (또는 ax-project.html) | conversion |
| 3 | `about-ax.html` | content |
| 4 | `methodology.html` | content |
| 5 | `community.html` | community |
| 6 | `pool.html` | community |
| 7 | `terms.html` | legal |
| 8 | `privacy.html` | legal |
| 9 | `contact.html` | (별도 처리, 선택) |

### CTA 마킹 (Conversion 페이지)

`index.html`의 Hero 영역 주요 버튼에 `data-cta` 속성 추가:

```html
<!-- Before -->
<a href="/pages/ax-project.html" class="btn-primary">AX 프로젝트 접수</a>

<!-- After -->
<a href="/pages/ax-project.html" class="btn-primary" data-cta="hero_ax_project">
  AX 프로젝트 접수
</a>
```

## Step 4. 4주 측정 운영 (1~5주)

### 주간 점검 KPI (월요일 09:00)

| 지표 | 측정 위치 | 목표 |
|---|---|:---:|
| 일평균 세션 수 | Vercel Analytics > Visitors | ≥10 |
| 누락 이벤트율 | (의도 클릭 - 기록 클릭) / 의도 클릭 | ≤5% |
| 페이지별 N | Pages 탭 | 페이지별 절대값 |
| 시간대 분포 | (커스텀 SQL 또는 export) | 주중/주말 분리 |

### 주차별 산출물

| 주차 | 산출물 |
|:---:|---|
| 1주차 종료 | N 잠정 측정 — N≥100이면 측정 종료, 아니면 계속 |
| 4주차 종료 | 베이스라인 KPI 표 + 시간대별 분포 + 95% CI(N≥30 시) / 점추정(N<30 시) |
| 5주차 | 옵션 A/B 임계값 재조정 + PO 게이트 통과 신청 |

### N 분기에 따른 행동

```
N ≥ 100 (1주 종료)
  → Task 3 (벤치마크 옵션 결정) 즉시 진행
  → A0 Task 4 임계값 재조정 → A1 진입

30 ≤ N < 100 (4주 종료)
  → 보수적 해석 + 옵션 A 폴백 권고
  → A0 Task 4 임계값 재조정 (95% CI 사용)

N < 30 (4주 종료, 측정 불가)
  → 비즈니스 KPI 사용 보류
  → 생산성 KPI(리드타임 -20%, CSS 중복 -20%) 단독 트랙
  → PO 별도 승인 기준 3건 충족 검토
```
