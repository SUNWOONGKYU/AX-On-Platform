## 🎯 핵심 결론

**현재 common.css는 이미 4축 토큰 체계를 갖추고 있다.** MBO v5의 토큰 명세는 forward-looking 표준이고, 현재 토큰은 다른 네이밍으로 동등 기능을 제공 중이다.

**A1 진입 시 작업**: 토큰 추가가 아니라 **별칭(alias) 추가 + 점진적 리네이밍**.

## 🎨 A1 진입 시 적용 계획 (Task 1, 4h)

### Step 1: 별칭(alias) 추가 (1h)

`common.css :root` 끝에 다음 블록 추가:

```css
  /* ============================================================
     MBO v5.1 표준 토큰 별칭 (2026-04-28~ A1 Task 1)
     기존 토큰을 v5.1 명명 규칙으로 노출 (legacy 호환 유지)
     ============================================================ */

  /* 컬러 */
  --brand: var(--amber);
  --brand-100: var(--amber-soft);
  --brand-300: var(--amber-light);
  --brand-500: var(--amber);
  --brand-700: var(--amber-deep);
  /* --brand-900: 신규 정의 필요 (#7a4f06) */
  --brand-900: #7a4f06;

  --accent-warm: #fb923c;          /* orange-400, Community 그룹 */
  --accent-neutral: #64748b;       /* slate-500, Legal 1차 */
  --accent-neutral-strong: #334155;/* slate-700, Legal 강조 */

  --text-primary: var(--ink);
  --text-muted: var(--ink-muted);
  --bg-base: var(--surface);
  --bg-elevated: var(--surface-card);
  --border-subtle: var(--border-soft);

  /* 타이포 */
  --fs-hero: var(--fs-display);
  --fs-page-title: var(--fs-h1);
  --fs-section: var(--fs-h2);
  --fs-card: var(--fs-h3);
  --fw-regular: var(--fw-body);
  --fw-medium: 500;
  --fw-semibold: 600;
  --fw-bold: 700;
  --fw-black: var(--fw-h1);

  /* 간격 (8px 배수 인덱스) */
  --sp-6: var(--sp-5);    /* 24px */
  --sp-8: var(--sp-6);    /* 32px */
  --sp-12: var(--sp-7);   /* 48px */
  --sp-16: 64px;          /* 신규 */
  --sp-24: var(--sp-9);   /* 96px */

  /* 컴포넌트 */
  --r-sm: 4px;             /* 신규 */
  --r-md: var(--radius-sm);/* 12px */
  --r-lg: var(--radius);   /* 16px */
  --r-xl: var(--radius-lg);/* 24px */
  --r-full: var(--radius-pill);

  --sh-1: var(--shadow-card);
  --sh-2: var(--shadow-card);
  --sh-3: var(--shadow-cta);

  --icon-sm: 16px;
  --icon-md: 20px;
  --icon-lg: 24px;
  --icon-xl: 32px;
```
