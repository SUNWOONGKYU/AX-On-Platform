## 🅰️ 옵션 A — 외부 공인 벤치마크 인용

### 개요

HubSpot이 매년 발간하는 **B2B SaaS 랜딩 페이지 전환율 벤치마크 리포트**를 인용하여 임계값을 보정한다.

### 후보 출처 (우선순위 순)

| # | 출처 | 신뢰도 | 접근성 |
|:---:|---|:---:|:---:|
| 1 | **HubSpot 2024 Conversion Benchmarks Report** | ★★★★★ | 무료 (이메일 등록) |
| 2 | Unbounce Conversion Benchmark Report 2024 | ★★★★ | 무료 |
| 3 | WordStream B2B SaaS Industry Benchmark | ★★★ | 무료 |
| 4 | Google Analytics Industry Benchmarks | ★★★ | GA4 계정 필요 |

### 산식 예시 (HubSpot 2024 가정값)

> **주의**: 아래 수치는 예시. 실제 리포트 다운로드 후 PO가 직접 확인 필요.

```
B2B SaaS 평균 전환율: 2.35% (HubSpot 2024)
상위 25%: 5.31%

베이스라인 1.8% 가정 시:
  → +3% 절대값 = 4.8%로 상향 = 상위 35% 수준 (현실적)
  → +0.55% 절대값 = 평균 도달 (보수적)

권장 임계값:
  - 비즈니스 KPI Δ: 베이스라인 기준 +2.5% 절대값 (상위 30% 진입)
  - 리드타임 Δ: -20% (생산성, 외부 무관)
```

### 장점

- ✅ 경영진·외부 투자자 보고 시 **신뢰성 확보** (출처 인용 가능)
- ✅ 업계 평균 대비 위치 파악 가능 (객관적 비교)
- ✅ N<30 케이스에서도 적용 가능 (자체 데이터 의존 X)

### 단점

- ⚠️ HubSpot 표본은 **북미·유럽 SaaS 위주** — 한국 B2B 컨설팅 시장 편차 있을 수 있음
- ⚠️ 리포트 발간 주기 1년 — 시장 변화 반영 지연
- ⚠️ "B2B SaaS"는 광범위 — AX-On 같은 컨설팅·전문 서비스는 하위 카테고리

## 🅱️ 옵션 B — 자체 4주 데이터 단독 사용

### 개요

A0 4주 측정 결과를 **상대 변화율** 기준으로만 사용. 외부 벤치마크 인용 없음.

### 산식 예시

```
A0 베이스라인 (4주 평균):
  - Hero CTA 클릭률: x%
  - /pool 도달률: y%
  - /ax-project 도달률: z%

Phase B 진입 임계값:
  - 비즈니스 KPI Δ: 베이스라인 대비 상대 변화율 +20% (예: 1.8% → 2.16%)
  - 리드타임 Δ: -20%

A1 종료 측정 시:
  - 베이스라인 대비 +20% 미만 → Phase B 미진입
```

### 장점

- ✅ AX-On 자체 컨텍스트 100% 반영 (한국 B2B AX 컨설팅)
- ✅ 외부 의존성 0 — 출처 분쟁 없음
- ✅ 베이스라인이 N≥30이면 **95% CI** 산출 가능 (통계적 엄밀성)

### 단점

- ⚠️ N<30 시 통계적 무의미 — 옵션 B 단독 사용 불가 (옵션 A 폴백 강제)
- ⚠️ 외부 보고 시 "왜 +20%인가"에 대한 객관적 근거 부재
- ⚠️ 베이스라인 자체가 비정상 트래픽일 가능성 (런칭 직후 등)

## 🅰️🅱️ 옵션 A+B — 하이브리드 (권장)

### 개요

**임계값을 단일값이 아닌 범위(range)로 표시**:
- 하한: 자체 4주 데이터 +20% 상대 변화
- 상한: HubSpot B2B SaaS 평균 절대값

### 산식 예시

```
A0 베이스라인: 1.8% (자체 측정)
HubSpot 2024 B2B SaaS 평균: 2.35%

Phase B 진입 임계값 범위:
  하한: 1.8% × 1.20 = 2.16% (자체 +20% 상대)
  상한: 2.35% (HubSpot 평균)

A1 결과 해석:
  ≥ 2.35% → 강한 진입 신호 (업계 평균 도달)
  2.16~2.35% → 진입 (자체 +20% 충족)
  < 2.16% → 미진입
```

### 장점

- ✅ 자체 컨텍스트 + 외부 객관성 양립
- ✅ N<30 시 옵션 A로 자동 폴백 가능
- ✅ PO·경영진 모두 납득 가능

### 단점

- ⚠️ 임계값 표가 복잡해짐 (단일값 → 범위)
- ⚠️ "범위 안에 들어왔다"의 해석 룰 추가 필요

## 📊 N 분기별 옵션 적용

| N 분기 | 적용 옵션 | 근거 |
|:---:|:---:|---|
| N ≥ 100 | **A+B** 하이브리드 | 베이스라인 신뢰도 충분 + 외부 비교 가능 |
| 30 ≤ N < 100 | **A+B** 하이브리드 (보수적) | 베이스라인 95% CI 산출 가능, 외부 폴백 안전망 |
| **N < 30** | **A 단독** | 자체 데이터 통계 무의미 → 외부 벤치마크만 사용 |
