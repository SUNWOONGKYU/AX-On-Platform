## 🔴 v5-x1 (HIGH) 재사용률 단위 이중 정의 해소

### 문제

| 위치 | 표현 |
|---|---|
| KPI 표 (행 175) | "**CSS 중복 라인 감소율 -20%**" |
| N<30 PO 승인 기준 (행 79) | "재사용률 **+20%**" |

→ 같은 지표가 두 단위로 표기됨. PO가 무엇을 보고 승인할지 모호.

### 결론 (v5.1)

**단일 단위로 통일**: `CSS 중복 라인 감소율 -20%`

**근거**:
- 측정 도구 명확 (`css-stats`, PostCSS analyzer로 라인 수 카운트 가능)
- "재사용률 +20%"는 분모/분자 정의가 필요 → 측정 분쟁 소지
- 라인 감소는 자동화 가능, 재사용률은 수동 산출 불가피

### v5.1 패치

```diff
- | (a) | 생산성 KPI 모두 충족 | 리드타임 -20% + 재사용률 +20% + 토큰 위반 0건 |
+ | (a) | 생산성 KPI 모두 충족 | 리드타임 -20% + CSS 중복 라인 -20% + 토큰 위반 0건 |
```

## 🟡 v5-x3 (MEDIUM) 95% CI vs N<30 모순 해소

### 문제

| 위치 | 표현 |
|---|---|
| A0 게이트 (b) (행 52) | "N 데이터 확보 — 페이지별 + 시간대별 + **95% 신뢰 구간**" |
| N 분기 룰 (행 74) | "N<30 — 측정 불가" |

→ 통계적으로 N<30이면 95% CI 산출 자체가 불가능. 게이트가 영원히 통과 못 함.

### 결론 (v5.1)

**N에 따라 통계 요건 분기**:
- N ≥ 30 → 95% 신뢰 구간 산출 (정규근사 + bootstrap)
- N < 30 → **점추정만** (CI 없음, 추세선 보고)

**근거**:
- 중심극한정리 표본 임계값 N=30은 통상 통계적 합의
- N<30 케이스는 어차피 PO 별도 승인 트랙 → CI 요건 의미 없음

### v5.1 패치

```diff
  - (b) N 데이터 확보 — 페이지별 + 시간대별(주중/주말 분리) +
-       95% 신뢰 구간
+       N≥30 시 95% 신뢰 구간 / N<30 시 점추정 + 4주 추세선
```

## 🟢 v5-x4 (LOW) A1 산출물 가치 미검증 해소

### 문제

리스크 표 행 212: "A1 산출물(토큰·공통 클래스)은 그 자체로 가치 — 손실 아님"
→ "그 자체로 가치"가 검증되지 않은 가정. 가치를 어떻게 측정?

### 결론 (v5.1)

**A1 자체 가치 = 생산성 KPI 리드타임 -20% 달성 여부로 측정**

**근거**:
- 비즈니스 KPI(전환율)은 N에 따라 측정 불가 가능
- 그러나 리드타임은 N과 무관하게 측정 가능 (작업 로그 기반)
- 리드타임 -20%면 A1 단독으로도 ROI 입증

### v5.1 패치

```diff
- | Phase B 임계값 미달 시 매몰비용 | A1 산출물(토큰·공통 클래스)은 그 자체로 가치 — 손실 아님 |
+ | Phase B 임계값 미달 시 매몰비용 | A1 산출물 가치 = 리드타임 -20% 달성 여부로 측정 (N 무관) |
```
