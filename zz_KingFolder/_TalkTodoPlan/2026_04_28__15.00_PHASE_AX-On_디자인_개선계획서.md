# AX-On Platform 디자인 개선계획서

**작성일**: 2026-04-28
**기반**: 3 페르소나 (Apple HIG / Stripe·Linear / 한국 시니어 UX·접근성) 검토 + 토론 결론
**P0 (5건)**: 별도 커밋으로 즉시 적용 완료 — 본 문서는 **P1·P2** 후속 계획

---

## 디자인 철학 (3 페르소나 합의문)

> **"메시지의 정직함 + 결정 가능한 동선 + 모두를 위한 가독성."**
>
> 모든 디자인 결정은 다음 3 게이트를 통과해야 한다:
> 1. **이 요소가 메시지 전달에 필수인가?** (Apple HIG)
> 2. **이 요소가 의사결정자의 다음 행동을 만드는가?** (Stripe/Linear)
> 3. **이 요소가 50대 한국인이 안경 없이 읽을 수 있는가?** (WCAG AA + 한국화)

## P1 — 다음 스프린트 (구조 변경 동반)

### Phase 1.1 — Hero 재설계 (B 강력 + A 평면 + C 한글)

**문제**: 현재 Hero는 텍스트 중앙정렬 800px 박스 + 좌우 거대 radial blob 2개. B2B SaaS 답지 않고 A 미니멀에도 어긋남.

**합의안**:
- [ ] 좌우 2-컬럼 레이아웃 (1280px max-width 활용)
- [ ] 좌측: 카피 + CTA 2개 (좌측 정렬)
- [ ] 우측: **5 Phases 다이어그램 (한글 라벨)** — 단색 라인, 그래디언트 없음
- [ ] `::before` `::after` radial blob 두 개 모두 삭제
- [ ] H1 `clamp(36, 5vw, 56)px`로 확대 (현재 28~42)
- [ ] Hero 우측 다이어그램은 SVG 1개 파일로 분리 (`assets/diagrams/5-phases.svg`)

**의사결정 필요**:
- Q1. 5 Phases 다이어그램의 시각 스타일 — 단순 박스 5개 일렬 / 흐름 화살표 / 원형 시계방향 / Stage Gate 표현?
- Q2. 우측 다이어그램에 호버 인터랙션을 둘 것인가 (B 제안) vs 정적 시각만 (A 추천)?

### Phase 1.2 — CTA 카피·동선 재설계

**문제**: 현재 H1+CTA 모두 공급자(전문가)만 부른다. 양면 마켓플레이스 함정.

**합의안**:
- [ ] Hero Primary CTA: **"기업 AX 프로젝트 문의"** → `ax-project.html`
- [ ] Hero Secondary CTA: **"AI 전문가 등록 안내"** → `pool.html#register`
- [ ] H1 카피 변경: "AX-On이 ... AI 전문가가 함께합니다" → **"기업 AX, AX-On이 책임지고 실행합니다"**
- [ ] 모든 2차 CTA의 "보기/알아보기" → outcome 동사 (단, 정중한 한글 톤 유지)
  - "방법론 전체 보기" → "방법론 알아보기" 또는 "AX-On 방법론 한눈에"
  - 마케팅 어휘("5분 만에", "시뮬레이션") **금지**

### Phase 1.3 — 타이포 위계 4-tier

**문제**: H1·H2·H3 모두 weight 800/900 + Noto Sans KR 400/700만 로드 → fake-bold.

**합의안**:
- [ ] Noto Sans KR 가변 폰트(`wght@400..900`) 또는 `300;400;500;700;900` 5단계 로드
- [ ] 위계 정립:
  - H1 (Hero) = 900, clamp(36, 5vw, 56)
  - H2 (Section) = 800, clamp(28, 4vw, 42)
  - H3 (Card title) = 700, 18~20px
  - Lead (H2 직하) = 500, 20~22px, color: var(--ink)
  - Body = 400, 16px, color: var(--ink-muted)
- [ ] eyebrow caps 13px + letter-spacing 1.5px (이미 일부 적용)

### Phase 1.4 — Trust Stack 신설 (B 핵심 제안)

**문제**: 신뢰 시그널 0개. "법인 설립 추진위원회"가 푸터에 노출되어 CFO·법무 게이트 통과 불가.

**합의안 (점진적)**:
- [ ] Step 1 — 푸터 카피 정직화: "AX-On 법인 설립 추진위원회" → "AX-On Inc. (설립 진행 중, 2026년 ○월 출범 예정)"
- [ ] Step 2 — 사업자번호·통신판매업 신고번호 우측 정렬 자리 확보 (값은 등록 후)
- [ ] Step 3 — index.html 신규 섹션 "추진 체계" — 어드바이저 4~6명 카드 (실명+직함, 사진 없으면 이니셜 모노그램)
- [ ] Step 4 — Logo Cloud 자리 (파일럿 기업 확보 시 활성화, 그 전에는 "Coming Q3 2026" placeholder)

### Phase 1.5 — 외래어 한글 병기 (C 제안)

**문제**: DID·SAL Grid_AX·STA·H·A·R·P·X 등 영문 약어 폭격 → 시니어 인지 부하.

**합의안**:

## P2 — 후순위 (구조 변경 최소)

### Phase 2.1 — 디자인 토큰 강제 적용 (B 제안)

**문제**: `--radius-sm/--radius/--radius-lg` 정의했으나 실제 사용은 `14px / 12px / 50px` 혼재.

**합의안**:
- [ ] `border-radius` 값 일괄 검사 → 모두 토큰화
- [ ] `--radius` 28px → 16px, `--radius-lg` 28px → 24px로 축소 (A 제안)
- [ ] 신규: `--radius-pill: 999px` (배지 전용)

### Phase 2.2 — Hover 4-tier 토큰화 (B 제안)

**문제**: 모든 호버가 `translateY(-2~-4px) + shadow 증대` 동일 패턴 → "전부 클릭 가능" 평탄화.

**합의안**:
- [ ] `--hover-cta-primary`: scale 1.02 + amber-glow
- [ ] `--hover-card`: translateY -2px + shadow-card
- [ ] `--hover-link`: color shift only (var(--ink))
- [ ] `--hover-nav`: background tint (rgba ink/0.04)
- [ ] 페이지별 적용 일관화

### Phase 2.3 — Empty State 행동 유도 (B 제안)

**문제**: pool/community 검색 0건 시 "검색 결과가 없습니다"에서 종료 → 이탈.

**합의안**:
- [ ] 검색 0건: "필터 초기화 / 인기 분야 / AX-On 직접 매칭 의뢰" 3 액션 칩
- [ ] 빈 컬렉션: "기업 프로젝트 의뢰 → AX-On이 큐레이션" CTA
- [ ] 일러스트는 단색 라인 SVG (현재 이모지 사용 금지 규칙 연속)

### Phase 2.4 — 컬러 팔레트 격리 (A 강력 제안)

**문제**: amber·coral·teal·violet·sky 5개 hue 동시 등장 → "색맹 검사표".

**합의안**:
- [ ] amber: 브랜드·primary CTA 전용
- [ ] ink/ink-muted: 모든 텍스트
- [ ] teal/coral/violet/sky: `.chart` `.viz` 네임스페이스로 격리 (데이터 시각화 전용)
- [ ] nav-links:hover violet → ink
- [ ] section-label `hl-orange/hl-teal` 동시 사용 → 단일 색

### Phase 2.5 — 이모지 → SVG 라인 아이콘 (A 제안, P0 후속)

**문제**: P0에서 `aria-hidden`만 적용. 시각적 일관성은 미해결.

**합의안**:
- [ ] Lucide Icons outline 24px 1.5px stroke 채택
- [ ] 색은 `var(--ink-muted)` 단일
- [ ] 또는 더 과감히 — 아이콘 제거하고 숫자(`how-step-num`처럼) 또는 단어로 대체

### Phase 2.6 — Legal 페이지 디자인 통합 (B 제안)

**문제**: terms/privacy가 마케팅 페이지와 시각 분리됨. "법무가 PDF 붙인 느낌".

**합의안**:
- [ ] eyebrow `LEGAL · 시행일 2026.03.01`
- [ ] 우측 sticky 조항 anchor TOC
- [ ] 표 헤더 amber-soft 배경
- [ ] 인용 콜아웃 `--surface-warm`
- [ ] H2 22~24px / H3 17px / p 16px 위계 강화

## 의사결정 요청 사항

### Q1. P1 진행 우선순위
- (a) Phase 1.1 + 1.2 (Hero 재설계 + CTA 동선) — **B2B 전환 임팩트 가장 큼**
- (b) Phase 1.3 + 1.5 (타이포 + 한글 병기) — **시니어 UX 가장 큼**
- (c) Phase 1.4 (Trust Stack) — **법인 설립 진행 상황과 연동 필요**

### Q2. 5 Phases 다이어그램 스타일
- (a) 박스 5개 일렬 + 화살표
- (b) Stage Gate 형태 (체크포인트 강조)
- (c) 원형 시계방향 (지속성 강조)
- (d) 외부 디자이너 의뢰

### Q3. 카피 톤 (B vs C 충돌)
- (a) outcome 동사 강하게 ("AX 도입 ROI 시뮬레이션 시작")
- (b) 정중한 한글 ("기업 AX 프로젝트 문의하기")
- → 잠정 결론: **(b) 정중한 한글** (한국 시니어 타겟 우선)

### Q4. Trust Stack 데이터
- 어드바이저 명단·사진 확보 가능 시점?
- 파일럿 기업 NDA 협상 진행 여부?
- 사업자등록·통신판매업 신고 일정?
